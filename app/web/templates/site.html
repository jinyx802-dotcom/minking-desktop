WHAT IT DOES

不是聊天窗口。它负责把工具接到线上。

客户端登录 MinKing 账号，切换本机配置，并在写入前留下可回退的版本。

一键接入

Codex、Grok、Claude Code、WorkBuddy、ZCode、Antigravity。写入前备份，还原时可以选择版本。

云端与本地官方

云端流量走 MinKing。本地官方模式继续用你已经登录的官方账号，流量不经过工作台。

文本、图片、视频

文本走各家对话模型。图片和视频走各自的生成接口，按张或按秒计价。

美元钱包与卡密

每把密钥一块美元余额。售价按官方价乘以系数。卡密兑换有每日次数上限。

技能由服务端下发

客户端安装工作台发布的技能包。没有单独去找环境变量的步骤。

会话原地同步

Codex 在官方登录和 API 密钥之间切换时，已有会话留在原处，不整包搬家。

MODEL LINES

同一把密钥，覆盖多条模型线路。

目录以工作台当时的定价为准。未定价的模型不会出现在客户端列表里。

OpenAI / Codex

GPT-6 Astra、Sol、Luna，以及 GPT-5.6 Sol、Terra、Luna。

xAI Grok

Grok 4.6 与 Grok 4.5，含图片和视频生成。

Gemini / Claude

Gemini 3.8 Flash、3.7 Flash、3.1 Pro，以及 Claude Opus、Sonnet 档位。

WorkBuddy

GLM 5.2、GLM 5.1、DeepSeek V4、Kimi、MiniMax、混元。

THREE STEPS

下载、登录、接入。

  1. 01

    下载客户端

    单个 MinKingAI.exe，双击运行，驻留系统托盘。无需安装，也不用解压。

  2. 02

    邮箱登录

    用工作台邮箱验证码登录。新人奖励每台电脑只发放一次。

  3. 03

    一键接入

    选择要切换的工具。官方配置会先备份，随时可以按版本还原。

ON-DEVICE TRUST

密钥留在设备上。

MinKing 不收集官方客户端的登录态。本地模式走你自己的官方账号。

API Key 不出本机

专属密钥写入本机配置和系统保护存储。网页工作台不展示完整密钥。

官方登录不上传

Codex、Grok、Claude Code、WorkBuddy、ZCode、Antigravity 的官方 cookies 和 tokens 留在你的设备。

可还原的切换

每次接入前保留上一版配置。还原时可以选择要回到的那一版。
